This page connects the MixedByRashid portal to the Dropbox app using OAuth PKCE. The refresh token is shown only in this browser so it can be saved directly into Netlify.

Dropbox refresh token

Treat this like a password. Save it in Netlify as DROPBOX_REFRESH_TOKEN. Do not send it in chat or screenshots.
